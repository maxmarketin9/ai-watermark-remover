# AI Watermark Lab v1.2

Static browser-based research app for controlled file transformation and AI-detector benchmarking.

## Supported
- Images: Canvas resize/re-encode and controlled visual transforms
- Audio: Web Audio decode, resample, filters, normalization, 16-bit WAV export (up to 10 minutes; browser memory permitting)
- Text: Unicode normalization and selected invisible-character cleanup
- Video: baseline copy in browser build for controlled comparison
- Batch processing, SHA-256, JSON/CSV reports, ZIP export

## Suno Audio Lab
Use the audio presets to create controlled variants of music files you are authorized to test. The app does not guarantee removal of proprietary invisible watermarks and does not claim AI output is human-authored.

## Deploy
Static site. Netlify publish directory: repository root.
